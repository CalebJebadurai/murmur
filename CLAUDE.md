# murmur — Claude Code Project Guide

Generated by Murmuration (Claude Code target).

## Available Agents

- **analyst** — Use when: deep codebase or domain analysis is needed before planning.
- **architect** — Use when: a task needs strategic analysis and a phased, multi-section plan before implementation begins.
- **business-critic** — Use when: a plan must be evaluated for business viability, unit economics, and go-to-market strategy.
- **critic** — Use when: a plan, design, or implementation needs critical review to surface weaknesses, gaps, and unstated assumptions.
- **curator** — Use when: the project's knowledge base must be initialized, reconciled, or kept current — after any task that changes architecture, structure, dependencies, build, deployment, or environments.
- **data-critic** — Use when: verifying statistical claims, auditing data science methodology, checking mathematical correctness, or stress-testing quantitative results.
- **fact-checker** — Use when: specific factual claims in a document must be verified against primary sources.
- **implementer** — Use when: a finalized plan must be translated into concrete, step-by-step changes grounded in the target stack.
- **master** — Use when: a task needs decomposition and coordination across multiple specialists, or when no existing specialist fits and a new one must be spawned.
- **planner** — Use when: research findings and critic feedback must be synthesized into a stronger, refined plan.
- **prompt-engineer** — Use when: a rough or naive user prompt must be refined into a structured, precise brief before strategic work begins.
- **research-critic** — Use when: research quality must be audited against academic rigor and methodological standards.
- **researcher** — Use when: a question needs information gathered and synthesized from sources, docs, or the codebase.
- **social-critic** — Use when: evaluating a plan, feature, or architecture from a social impact, user welfare, accessibility, and equity perspective.
- **verifier** — Use when: an implementation report must be cross-referenced against its source plan for coverage gaps.

## Subagents

- **example-specialist** — Use when: the master agent needs an example specialist to demonstrate the spawn-and-dispatch loop.

## Skills

- **build-system** — How this project is built, tested, and run — package manager, scripts, bundler.
- **compiler-architecture** — How the compiler turns the abstract IR into each runtime's native files via the RuntimeCompiler adapter interface.
- **knowledge-curation** — The procedure the curator agent follows to inventory, initialize, and keep a project's knowledge base (skills + instructions) current as the single source of truth.
- **project-structure** — How this project's directories, modules, and entry points are organized.
- **project-tools** — Discovered operational development tools and scripts for agent execution.
- **schema-and-ir** — The shape of the abstract IR — the murmur/ directory, its six definition kinds, and how loadIR parses and validates them.
- **subagent-authoring** — Rules the master agent follows to author a scoped subagent on demand.
