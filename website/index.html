04 Hierarchical Knowledge Inheritance

The Three-Tier Experience Cascade

Persistent agent memory without polluting unrelated repositories. Murmuration resolves directives across three isolated scopes using deterministic CSS-like specificity.

Tier 1 • Priority 100 (Highest) Git Repo Scope

Project Experience

./murmur/EXPERIENCE.md

Strictly bound to the project repository. Captures verified Harness² lessons, service architecture quirks, and repo-specific invariants. Never leaks to other projects.

Active Override Directive "Use Bun native test runner (bun test); reject Vitest or Jest."
Tier 2 • Priority 50 Workstation Scope

User Profile Experience

~/.murmur/experience.md

Persists across all repositories on your workstation. Stores personal coding idioms, preferred CLI flags, commit message conventions, and ergonomic defaults.

Workstation Default Directive "Default to Vitest for TypeScript projects; prefer functional style."
Tier 3 • Priority 10 (Baseline) Global Pack Scope

Curated Ecosystem Packs

curated/ecosystem/*.md

Community-vetted baseline packs for security, OWASP compliance, and language best practices. Automatically inherited unless explicitly overridden by Tier 1 or Tier 2.

Community Baseline Directive "Run unit tests via npm test; enforce OWASP Top 10 secret checks."
